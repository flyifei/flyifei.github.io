How to add an entry

Add one row to the end of the relevant table, then update the totals table at the top of the page. 

<tr>
  <td>2026-12-01</td>
  <td>A320neo</td>
  <td>B-LCN</td>
  <td>VHHH → VMMC</td>
  <td>1.2</td>
  <td>2</td>
  <td>What was practised, and what went wrong</td>
</tr>

Route airports use ICAO codes: VHHH Hong Kong, VMMC Macau, VHSK Shek Kong, EGLL London Heathrow, YPPF Parafield. Keep a copy of the file outside the repository as well — there is no database behind this page.
