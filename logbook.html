How to add

怎么新增一条记录

数据存在两个 JSON 文件里，加一行数组元素即可，页面会自动重算统计。

文件位置

  • ◆ 模拟机：assets/data/msfs.json
  • ◆ 真实飞行：assets/data/real-flights.json
  • ◆ 本地预览命令见 README.md
◆
复制一条现成的记录，改日期和数值最省事。JSON 里最后一条后面不要多逗号。

一条记录的字段

{
  "date": "2026-12-01",
  "type": "A320neo",
  "reg": "B-LCN",
  "from": "VHHH",
  "to": "VMMC",
  "hours": 1.2,
  "ldg": 2,
  "cat": "区域航线",
  "remarks": "今天练了什么、哪里出错"
}

hours 为小时（可小数），ldg 为降落次数， from/to 用 ICAO 四字码（VHHH 香港、VMMC 澳门、EGLL 伦敦希思罗）。
